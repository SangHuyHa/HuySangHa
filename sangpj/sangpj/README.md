# Website giới thiệu bản thân (Bài tập 2)

Website tĩnh responsive của Hà Huy Sang, làm bằng HTML5 và CSS3.

## Cấu trúc thư mục

```
project/
├── index.html       Trang chủ
├── about.html       Giới thiệu và sở thích
├── education.html   Học tập
├── products.html    Kỹ năng
├── pj.html          Dự án
├── gallery.html     Thư viện ảnh
├── blog.html        Blog chia sẻ
├── contact.html     Liên hệ
├── css/
│   └── style.css    CSS dùng chung (Grid, Flexbox, Media Queries)
├── images/          Ảnh (sang1.jpg là ảnh cá nhân)
└── README.md
```

## Responsive
- Máy tính: grid 3 cột
- Máy tính bảng (dưới 900px): grid 2 cột
- Điện thoại (dưới 600px): grid 1 cột

## Nguồn ảnh
- sang1.jpg: ảnh cá nhân
- Các file .svg: hình minh họa tự tạo

## Cách chạy
Mở file `index.html` bằng trình duyệt.

Demo: https://TEN-GITHUB.github.io/TEN-REPO/
