# Website giới thiệu bản thân

Website giới thiệu cá nhân của Hà Huy Sang, làm bằng HTML và CSS.

## Cấu trúc thư mục

```
project/
├── index.html      Trang chủ
├── about.html      Giới thiệu bản thân và sở thích
├── products.html   Kỹ năng
├── contact.html    Liên hệ
├── css/
│   └── style.css   File CSS dùng chung cho tất cả các trang
├── images/         Thư mục chứa hình ảnh (bỏ ảnh anh-cua-toi.jpg vào đây)
└── README.md       File mô tả dự án
```

## Cách chạy

1. Giải nén thư mục `project`.
2. Bỏ ảnh cá nhân vào thư mục `images/` và đặt tên là `anh-cua-toi.jpg`.
3. Mở file `index.html` bằng trình duyệt.
